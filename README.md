# TeleRehab

TeleRehab is a native Android tele-rehabilitation project focused on production-quality Android engineering, local-first rehabilitation sessions, camera-based movement analysis, reliable synchronization, and secure patient/therapist workflows.

The project is being developed incrementally through explicit engineering milestones.
